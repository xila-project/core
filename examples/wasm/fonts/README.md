# Xila web typography

Deployment copies from `xila-project/brand`, commit `a7f0b4441c2328935d92970a585cdfe999f0537e`, identity version `1.1.0`.

Montserrat 9.000 is the shared proportional family: Regular 400 for text, SemiBold 600 for headings, and Bold 700 for emphasis. The local normal and italic variable WOFF2 files retain the upstream SIL Open Font License in `OFL.txt`. `montserrat.css` references only local font files.

Update these files from the reviewed brand export and record the exact imported commit. Do not edit the font binaries or fetch private repository assets during a consumer build. Monospace code and terminal fonts keep their existing independent role.
